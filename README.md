# Photography Website

Personal photography portfolio website built with Astro as a static site.

## Foundation

- Static Astro project
- Mobile-first layout and navigation
- Placeholder routes for Home, Event, Nightlife, Food, Portrait, Cars, Her, My Work, About, and Contact
- No CMS or database
- No photography assets stored in the repository

Production photography assets will be hosted outside Git, planned for Cloudflare R2.

## Commands

```sh
npm install
npm run dev
npm run build
```
